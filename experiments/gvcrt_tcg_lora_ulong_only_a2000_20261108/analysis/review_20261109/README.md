# ULong-only A2000 续训独立复核（2026-11-09）

结论：实验完成，当前保存结果的数值、码流、采样与检查点核验通过。修复采样后只用 ULong 续训，使 ULong 测试集小幅改善，但 HEVC-B、MCL-JCV、UVG 相对 A2000 s=0.5 的感知指标均退步。这是域内收益与跨数据集退步并存的结果，不能描述为全面升级。

本复核仅使用 CPU 读取检查点、日志、码流与逐帧记录、重新聚合指标；没有重新运行模型、GPU 训练或质量网络。源实验文件没有改动。

## 实际训练与选模

- 起点：A2000，SHA256 为 8a69765befa6ed267d0a95d3932cd63d9513c1da9818fd2126d8bc1c165f5e4e。
- 只训练 stage3 四个旁路和 head 共 59,392 个 LoRA 参数；TCG、Bridge、codec、生成器原始参数冻结，无 Router。没有新增多尺度 LoRA。
- 恢复了父检查点的 LoRA、AdamW 状态和四个逻辑进程 RNG；CPU 逐项比较一致。
- 学习率 5e-5；s_train=1.0，s_eval=0.5。没有改损失或按 QP 调整 LoRA 强度。
- 完成 1,750 个新增 optimizer updates，末尾绝对 LoRA 步数 3,750；选中新增 +750，即绝对 LoRA 步数 2,750。TCG 累计步数始终冻结在 6,500。

## 怎样解释，下一步怎样做

1. 证据首先支持“域内适配与跨域退步”：训练与选模均仅依赖 ULong，ULong 开发集及两套 ULong 测试改善，其他三个数据集退步。采样确实更丰富，但更多同域视频不自动保证跨域改善。
2. 本实验同时移除 UVG、改变采样并增加训练更新，没有旧采样的等预算对照。不能单独证明是删除 UVG、采样策略或某个 loss 导致退化，也不能据此断言 Conv-LoRA 的代码或结构错误。
3. 退化不限于片段最后几帧：QP9 下 MCL 的四个 16 帧左右分段 DISTS 分别退化约 0.39%、0.81%、0.87%、0.86%；UVG 对应约 1.58%、2.05%、2.29%、2.39%。后段可能更明显，但不足以仅凭此认定 TCG 累积误差是根因。
4. 训练端仍以 s=1、推理端以 s=0.5 工作，这是已有设定而非本轮新变化。它可以作为后续独立受控变量，不是已经证明的失败原因。此次 loss 未改，只有 rate 的 beta(q) 随 QP 变化；codec 冻结时该项不能提供 LoRA 的有效码率梯度。
5. 现有 loss 图把未乘 0.01 的 motion_loss 与其他量放一起，不能按曲线高度认定 motion 项主导优化。不同更新使用不同视频窗口，原始总 loss 也不是同一固定样本上的收敛曲线。
6. 按冻结协议，本轮正式结果继续记为 +750；不要查看测试结果后重选其他步数或按测试视频调 s。研究上保留它作为 ULong 专项适配结果，A2000 s=0.5 保留为后续通用对照，不宣布本轮全面替代父模型。
7. 暂不直接放开 Bridge，也不沿用完全相同配置继续加步数。下一轮若目标是跨数据集性能，应先建立与最终测试隔离的多域开发集/预先冻结约束；保持这次已修好的采样。增加训练域或对齐 s_train/s_eval 应分开做，避免同时改数据、loss、可训练模块而无法归因。新的开发数据不得直接拿这些已观察的最终测试点充当未见验证集。
