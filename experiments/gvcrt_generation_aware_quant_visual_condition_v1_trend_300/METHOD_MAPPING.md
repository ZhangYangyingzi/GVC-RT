# Method mapping

- `src/models/video_model_gvcrt.py`: `DMC.res_prior_param_decoder` fuses decoded `z_hat` and causal `ctx_t` into `common_params` `[B,384,H/16,W/16]`. Its channel chunks are base quantization step, Gaussian scale and mean, each `[B,128,H/16,W/16]`. The existing codec already predicts a local step.
- `src/models/common_model.py`: `compress_prior_2x` and `decompress_prior_2x_part1/part2` code two checkerboard passes. `y` is `[B,128,H/16,W/16]`; their means, scales and first-pass reconstruction are in the normalized latent domain. `y_spatial_prior` consumes first-pass normalized reconstruction concatenated with unchanged common parameters.
- The experiment's quantizer uses only `common_params` and actual QP. A 4×4 block map `[B,1,ceil(H_y/4),ceil(W_y/4)]` is repeated to the latent size. `m=exp(log(2)*tanh(H(common_params,QP)))`, `q_base=clamp_min(common_params[:,:128],.5)`, `q_new=clamp_min(q_base*m,.5)`. The final H layer is zero initialized. Encoder and decoder both compute the map after `z_hat` has been decoded; no map is transmitted.
- Domain equations for both checkerboard passes: `u=y/q_new`; `r_i=round(u-mean_i)` subject to the existing symbol clamp and skip rule; `u_hat_0=r_0+mean_0` feeds the frozen spatial prior with the **original** common parameters; `u_hat=u_hat_0+r_1+mean_1`; `y_hat=q_new*u_hat`. Gaussian scales and means retain their original normalized-domain numerical convention. Differentiable training uses STE symbols and continuous Gaussian CDF rate with both y and z terms.
- `src/models/improved_model_gvcrt.py`: generator receives bridge codeword `[B,18,H/16,W/16]` and has existing AdaGN. The added spatial condition uses decoded feature `[B,256,H/8,W/8]`, receiver quantization map, prior summaries and QP. Its 32-channel bottleneck drives zero-initialized affine residuals after `stage2` (`[B,512,H/16,W/16]`) and `stage4` (`[B,320,H/8,W/8]`): `h_out=h*(1+gamma)+beta`. The original AdaGN remains active.
- `src/models/video_model_gvcrt.py`: `DMC.compress` updates reference with `dec(y_hat,ctx,q_decoder)`; `DMC.decompress` uses the same feature, then generates RGB. This reference update rule is retained. Native I coding uses `image_model_gvcrt.py`. External QP shifts are from `gvc_hooks.INDEX_MAP`; source frame pixels and future frames are never inputs to either new receiver module.
