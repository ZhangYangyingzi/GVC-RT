# GVC-RT V1.3 — 固定增强解码器的码字优化诊断

日期：2026-09-15。结果：`results_v1/`。本轮已完成授权的有界实验，**网络参数更新次数为0**。

## 1. Q1、Q2独立结论

| 问题 | 实测结论 |
|---|---|
| **Q1：固定D_enh，是否找到明显优于当前编码器的连续码字？** | **是，就L_image与PSNR而言。** 六训练帧相对编码器连续输出+0.245522 dB；其余24P帧+0.269143 dB；Val6的90P帧+1.133508 dB。LPIPS并未在所有比较中同步改善，不能称为全面质量优势 |
| **Q2：是否找到10%/25%/50%预算内、真实码流上的有效增强？** | **本轮候选与150步预算下没有。** 完整Train2的非零有效候选均在至少一段超预算；所有三个目标预算均退回固定ZERO，增量为0。因此不扩展Q2到Val6 |

**对应下一步建议：连续码字改善明显，但低预算实际编码无效，应重点研究受码率约束的表示与编码。** 本轮不训练快速编码器，不更换D/G，不把有限步结果称作性能上限；也不因Q2未达标推断所有码字优化或所有增强表示无效。

## 2. 冻结接口与实验规则

仓库commit：`d0e32bfa3e8e282f9a77437c223c605858eea637`。未找到适用AGENTS.md。沿用gvc-rt环境（PyTorch2.6.0+cu124），只使用GPU6/A100，UUID `GPU-76210030-c72b-28f8-f8ca-f21276be4417`。初始计划GPU0在启动前被其他任务占用，预检拒绝启动后才固定GPU6；没有中断其他任务。

明确区分三个模型：

1. V1 stage_D旧enhancement.decoder，只定义固定ZERO：`ell_c=ell_base+D_V1_D(0,ell_base)`。
2. V1.2 `results_v1/stage_B/checkpoint_1500.pt` 的D_enh，本轮参数完全冻结。
3. 原G，冻结参数但保留对输入的梯度。

量化前物理码字为 **u:[1,8,17,30]，4080标量**。固定l3：delta=**9.042649269104004**，`s=round(u/delta)`，D实际输入为`u_hat=s.float()*delta`。各等级只改delta，无额外网络条件。

完整增强路径保留V1.2尺度：

```
pred_norm = D_enh(u_hat,ell_c) - D_enh(0,ell_c)
r_hat = pred_norm * frozen_Train6_residual_scale
x_hat = G(ell_c+r_hat,q_recon)
```

没有加回源均值；熵scale只用于概率，残差scale固定共享。整数零、量化域零与D输入零一致，F(0)严格为0。正常接收端只读取基础流、ORC2增强流和固定共享模型，源图、完整教师、优化码字缓存和基础训练缓存访问会被阻断。

质量沿用原生1080×1920有效RGB [0,1]、排除底部8行padding、原QP0及offset/reset=96、真实帧率、PSNR、五尺度RGB **MS-SSIM**、LPIPS Alex v0.1 normalize=True。P显示增强不回写基础预测，I保留原路径。

### 优化域、初始化、选择

- A在物理u域优化。两种初始化ENCODER_START/ZERO_START，Adam150次更新，目标MSE+0.001LPIPS，不用教师残差拟合。
- 六帧当前u的RMS中位数为6.886650，预定尺度规则给出`lr_u=0.02×median_RMS=0.1377329922`。
- B在z=u/delta量化域优化，`lr_z=0.01523148671`；前向为真实整数值，使用 `round(z).detach()+(z-z.detach())` 的STE保留梯度。
- A记录0/25/50/100/150，主点最小化L_image（含step0），全局初始化由六帧所选L_image均值决定。选中ENCODER_START。报告选中点及固定150步；本轮A中两者相同。
- B初始化预先固定ZERO_START，**编码算法不需要完整latent教师或当前E前向**。为对照读取历史教师并不构成该编码路径的必需依赖。
- B的检查点按最小`L_image+lambda×R_actual_frame_bpp`选择，含step0；正式预算只从真实完整序列候选选择，绝不跨lambda混帧。

所有自由变量始终是4080维码字；没有重新优化146880维完整生成latent。共享网络、归一化、熵模型及原始状态hash检查通过。ZERO_START实际走完整可微D/G路径，不因空流跳过而截断梯度。

### 估计率与真实率

`R_est_bpp = frozen_entropy.bits(STE_integer,delta)/(1080×1920)`，概率为固定logistic CDF在整数区间的质量。它忽略全零跳过的离散模式，零点仍平均估计约 **2083.307 symbol bit/P**。

实际全零P只有**8bit标志**，按预定头分摊后每P **54.4bit**；完整1I+15P全零文件为**102byte/816bit**。所以最终检查点选择和预算使用实际ORC2字节，而不是把估计率当实码率。

每个记录点都硬量化、写真实诊断容器并round-trip；优化前向也是硬量化值，未用软量化质量替代。D/G固定时、同帧同lambda且整数状态完全相同，可复用STE目标梯度；首次复用与新反向核对通过，记录缓存次数。这不改变硬前向，所有记录点仍重新硬渲染/编码。

## 9. 最终A–E回答与后续建议

**A. 固定D是否找到明显优于编码器的码字？** 是，PSNR/L_image支持，Val6改进比六帧更明显；LPIPS不保证同步改善，有限步结果不是性能上限。

**B. 是否找到预算内有效实际增强？** 没有，当前固定l3、三个非零lambda和150步规则下，逐段10/25/50%都只能退回ZERO。不能用合计35%的候选掩盖T1超预算。

**C. 是否优于相同预算规则下的现有E候选？** 没有，双方预算算法都退回相同ZERO。非预算内的率/质量取舍另列，不能混为预算胜利。

**D. 是否在重叠总码率下优于原版？** 部分T1实际点PSNR更高，但MS-SSIM与LPIPS更差，而且包含固定ZERO的既有作用；不能宣称全面RD优势，其他区间不外推。

**E. 泛化和茶园/桥梁在哪一环节？** Q1所有Val6视频PSNR均优于E连续，但3/6 LPIPS更差。茶园/桥梁在E连续路径已由教师的正PSNR收益变负，优化连续码字能恢复正收益；Q2 Val6未执行，低预算泛化证据不足。

下一轮应按“**连续改善明显，但低预算无效**”分支研究受码率约束的表示与编码：当前单一粗量化等级、估计率与全零实际模式差异、有限步/单一初始化的搜索以及每视频码率差异都可能限制结果。这里只提出研究方向，不自动训练新网络、扩大解码器、换注入点或启动蒸馏。
