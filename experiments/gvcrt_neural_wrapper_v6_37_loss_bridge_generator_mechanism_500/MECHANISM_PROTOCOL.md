# Receiver mechanism protocol

The frozen native-I/IP−1 protocol and exact v6.36 13-video64-frame manifest are retained: ULong6, UVGholdout2, HEVC-B5; external QP0/5/9. Only physical GPUs4–7 are used. I0 bypasses the P-frame receiver. Every evaluation input is hash-checked by inherited readers.

The actual codec feature f is the output of pm.dec after entropy decoding y_hat. The actual bridge is PretrainedReconWrapper.forward up to the input of its decoder: pixel_unshuffle, mlp[0], mlp[1], mlp[2], out*sigmoid(out), mlp[3]. This code is invoked directly and its18-channel decoder input is captured with a pre-hook. pm.dec is not the generator. Full module parameters and applicable buffers are loaded at FP16 deployment precision using the historical conversion; original FP32 training hashes are recorded separately.

For each stream, independent O/B/F decoders read identical persisted bytes. Per-P-frame y_hat, f and q_recon hashes, shapes, dtypes and actual reference state are recorded. After native I, apply_feature_adaptor selects the preceding feature; receiver RGB is not consumed when that feature exists. No reference replacement, I refresh or feedback modification is introduced.

Shared f/q_recon feed O/B/F receivers and the fixed swaps X=generator0(zF), Y=generatorF(z0), I=generatorF((z0+zF)/2). The midpoint uses actual latent tensors in their deployment dtype, not weights or RGB. Alpha0/1 are exact latent endpoint identities and alias Y/F; there is no scan beyond0/.5/1. D receives39 fresh real-RANS encode/paired-decode/independent-decode evaluations, compared byte-for-byte to original streams, followed by same-feature endpoint replay and B→D/D→F latent comparisons. Local latent archives are bounded per video/QP; no test-set tensor collection is retained on GPU.

Endpoint stages are compared before RGB crop/clamp, in identical dtype/padding. Prefer exact tensor hashes; numerical fallback must satisfy normalized RGB maxabs1e-5 and relativeL2 1e-6, metric absolute error1e-5 and pooledFID error1e-3. Thresholds cannot be relaxed. Direct endpoint replay values and historical verification attempts remain separately traceable. Failed endpoint reproduction is an implementation/blocking condition, not a mechanism result.

For latent statistics, each P frame's spatial positions are samples; per-channel mean/variance(ddof0), RMS/L2 and18×18 FP64 covariance are recorded. The actual codeword includes the codec's padded processing extent. Streamed aggregates combine space and P-frame samples using mean and covariance cross-moments, including between-frame mean variation. Covariance archives are SHA-indexed server artifacts. X aliases zF; Y aliases z0; identical content is not duplicated. No latent statistic is an Inception statistic or proof of quality/causal channel utility.

Metrics reuse the existing LPIPS/DISTS/FloLPIPS definitions and official Inception2048. FID is pooled per dataset:384/128/320 frames, FP64 ddof1 low-rank cross-SVD; D_mu and D_cov are retained. FloLPIPS uses63 actual transitions. Main equal-rate summaries use20 ln(bpp) interpolation points per video's common measured interval, no extrapolation, equal video weights; FID uses dataset mean actual bpp and pooled features. Grids are not independent observations. Same-stream anchors establish equal actual rate from complete byte/SHA equality, not from QP labels alone.

Fixed comparisons: D−B; F−D; B/D/F−O; X−O; F−Y; Y−O; F−X; Y/I/F at alpha0/.5/1. Negative metric differences mean lower distance. Cross-swaps may expose weight incompatibility and do not test independently trained modules. One seed,13 videos and500 updates do not establish convergence, significance, generalization, P value, sufficient original training, a causal latent attribute, or publication novelty.

Fixed examples use the first manifest video of each dataset, QP0/5/9 and frames16/32/48/63. All methods and GT use identical full-frame and fixed crop locations. No quality-dependent selection is allowed.
