# GVC-RT Latent Enhancement V1.1 — 诊断实测报告

日期：2026-09-14。结果目录：`results_v1/`。**三项诊断均已完成，网络参数更新次数为 0。**

## 结论先行

**下一轮应优先处理表示学习和“有益源信息”的利用：考虑固定一个明确质量取舍的无码流基线，再训练空输入增量为零的增强分支。** 本轮没有实现或训练该分支，也没有修改熵编码协议。

证据链如下：

1. **δ=2 确实没有新的源侧内容。** Val6 的 367,200 个增强整数全为零；实际反量化 `u_hat=symbols.float()*delta` 后仍全零，没有源相关均值/尺度。90 个 P 帧 REAL/ZERO 的 u_hat、delta_ell、G 输入 latent、完整 RGB 与有效区域 RGB 均 `torch.equal=True`、最大绝对差 **0**。
2. **当前模型对非零增强有响应，但未形成稳定有益的源信息利用。** δ=0.125/0.5 的 REAL 平均 PSNR 均低于同模型 ZERO；δ=0.125 的 WRONG_SOURCE 平均 PSNR 和 LPIPS 甚至都优于 REAL。不能把不同模型之间的 +0.0694 dB 解释成信息收益。
3. **未形成“连续源信息有效、只因量化而失效”的证据链。** CONTINUOUS 相对 ZERO 的完整 I/P 平均 PSNR 为 **−0.030291 dB**，MS-SSIM 为 **−0.000110**，LPIPS 为 **−0.000550**。这是很小的感知指标取舍，并非稳定的联合改善。
4. **全零流主要贵在概率模型失配，不是文件头。** 实际零概率约 0.699，每个零仍耗约 0.516 bit；符号编码占全部增强文件 **87.985%**，头信息占 **10.428%**。
5. **直接优化 latent 找到了更好的质量组合。** 六帧×两起点×两目标的 24 个运行均完成 150 步，无 NaN/Inf 或异常中止；24 个最终点都在各自样本上同时优于 V1 阶段 C 的无码流修正网络（PSNR 更高、LPIPS 更低）。六个样本均存在同时优于原版的 oracle 点。因此暂不优先更换注入位置或判定生成器不能利用额外信息。

这些 oracle 点是**单帧、有限预算、未编码的可达参考**，不是合法 RD 点、不是理论上界，也不证明现有轻量 E/D 能达到它们。

### D/G 真正收到什么

完整逐项来源分类见 `input_audit.md`；关键结果如下：

| 输入/量 | 来源 A/B/C/D | 实际作用 |
|---|---|---|
| ell_base | B：基础码流可计算 | D 与 G 的基础条件 |
| 增强整数、δ | C：增强文件；δ 在本档固定 | **唯一反量化式 `u_hat=s.float()*δ`** |
| D 权重、bias、插值规则 | A：固定共享 | D 接收 u_hat、ell；没有归一化/均值/尺度/hyperprior/QP 额外输入 |
| q_recon | A 的参数表 + B 的逐帧 QP | 仅进入 G，不进入 D |
| G 的权重/归一化权重 | A：固定共享 | 冻结，纯 PyTorch 可微路径 |
| G 内部 latent 均值/std | 由当前 ell_final 派生 | AdaptiveGroupNorm 的计算量，不是额外传输参数 |
| 熵模型 logistic scale | A：共享 checkpoint | **仅构造概率/CDF，不参与反量化**；固定零均值 |
| CDF CRC、shape/level、基础 hash | C 的格式字段，值由 A/B/固定档位产生 | 校验/解析；不作为 D/G 的隐藏条件；无 CDF 表/源均值/源尺度传输 |
| DPB、基础 hyperprior | B：基础层状态 | 在获得 ell 前使用；增强显示路径不写回、不直接读取 DPB |
| 原图 x | D：源端可用 | 仅 E 的发送端/CONTINUOUS、质量监督及 oracle；正常合成 API 不接收原图 |

所以“整数全零 → u_hat 全零”在本实现中成立。D 仍能从 ell 与已训练 bias 产生非零 delta_ell；**ZERO 从未触发无增强 bypass**。无需额外 UZERO 模式，因为实际零反量化与直接零 u 完全一致。

- V1 浮点概率估计：**189586.0986 bit**。
- 使用实际量化 CDF 的理想 `−log2 p` 总和：**189587.6493 bit**。
- 实际含全部头/终止的文件：**215424 bit**；比浮点估计多 **25837.9014 bit**。

CDF 离散化只有约 1.55 bit 的理想代价差，不是主要来源。真正大额的零编码开销已经存在于估计率中：约 189.6 kbit。剩余差额主要是格式与终止开销。

Coder **每个 P 帧重新初始化一次，共 90 次**；同一状态连续编码其 8 个通道，并非每通道重置。概率表是固定因子化模型，不按已看到的连续零自适应。没有 raw/fixed-length fallback。每帧重复的 shape/δ/level/CDF 指纹确有冗余，但占比小于概率失配。

**仅作估算：** 若保留现有全部头信息，另加 1 字节/P 帧的全零标志，并跳过全零网格的整个算术 payload，则总计约 **23184 bit / 7.0113 kbps**，潜在节省 **192240 bit / 58.1371 kbps（89.24%）**。这没有实现、不是实际新码率点，而且节约空流开销并不能证明新增信息有效。

### 非支配结果与不能忽略的取舍

在 **120 个记录的 oracle 快照 + 24 个参照**内，按 PSNR 最大化、LPIPS 最小化逐样本计算，得到 **14 个严格非支配点**，全部保留于 `oracle_nondominated.csv`：

- T1 三帧各保留 O+MSE_ONLY、O+MSE_LPIPS、Z+MSE_LPIPS 的第 150 步，共 9 点。
- T2 P1/P8 各保留 O+MSE_LPIPS 与 Z+MSE_LPIPS 的第 150 步，共 4 点。
- T2 P15 保留 Z+MSE_LPIPS 的第 150 步，1 点。

T1 的 O+MSE_ONLY 仅比 O+MSE_LPIPS 多约 0.0002–0.0005 dB，却有更差 LPIPS；它因严格数值判据留在集合中，不代表这个微小 PSNR 差有统计/视觉意义。不能由六帧平均 LPIPS 改善掩盖 T1 的 MSE_ONLY 相对原版 LPIPS 恶化。

24/24 最终点均同时优于各自的 base-only C；15/24 最终点同时优于原版 FP16。六帧每帧都至少有一个点同时优于原版。Z+MSE_LPIPS 通常给更高 PSNR，而 O+MSE_LPIPS 通常给更低 LPIPS；不存在一个单一目标/初始化在所有质量维度上无条件最好。

### 可视化和限制

已保存全部源图、原版、base-only、ZERO 起点和 oracle 输出，以及预先固定 crop；六组曲线、Pareto 图、完整对比与裁剪对比位于 `plots/`。观察人群/横幅和室内装饰区域：oracle 能调整部分伪纹理、对比和边缘，含 LPIPS 的目标相比纯 MSE 保留了更好的感知组合；但**细小文字仍错误或模糊，人物细节并未完整恢复**，不能把指标改善解释为真实细节全部找回。

每次优化的 delta 有 **146,880 个自由标量**，而 V1 的 u 网格仅 4,080 个标量，相差 36 倍且 oracle 完全未编码。最终相对修正 L2 范围约 **14.06%–23.96%**，全体记录的最大绝对修正约 **0.216009**。这些不是无限小扰动，也不证明轻量可传输 E/D 能达到同样效果。

G 参数冻结但梯度保留到 delta；24 运行的梯度、权重 hash、原始 ell/q/参考来源检查均通过。另对 12 个“样本×起点”验证了 step 0 的带梯度与无梯度 G 输出精确一致，排除切换数值路径导致的虚假收益。没有修改基础参考缓存。**本项是单帧诊断，不评价或宣称时间稳定性改善。**

## 5. 六个问题的直接回答与下一步

1. **δ=2 是否确实不含新的源侧内容？** 是。整数与实际 u_hat 全零；无隐藏均值/scale，所有同模型输出精确一致。头中基础摘要也只是已有基础信息的标识。
2. **细量化 REAL 是否优于 ZERO 和错配？** 没有稳定的联合优势。δ=0.125 平均 PSNR/MS-SSIM 低于 ZERO，且 WRONG_SOURCE 的平均 PSNR/LPIPS 都更好；δ=0.5 的 REAL 平均也没有优于 ZERO。
3. **是否连续有效、量化后消失？** 证据不支持此主因判断。连续表示有很小的平均 LPIPS 改善，但 PSNR/MS-SSIM 降低，只有 1/6 视频有相对 ZERO 的联合改善。
4. **全零流主要花在哪里？** 固定概率模型仍以约 0.699 的零概率支付每零约 0.516 bit，符号编码占 87.985%；头、终止与对齐是次要部分。全零标志有明显潜在节省，但本轮只是估算。
5. **直接 latent 优化是否优于无码流修正的质量组合？** 是，在六个固定样本与 150 步预算下均找到 PSNR/LPIPS 联合改善；保留了所有目标/起点及严格非支配点，不以 PSNR 单指标判定。
6. **优先处理什么？** 优先表示学习/源信息利用及优化目标的锚定。后续可考虑固定无码流基线、空输入增量严格为零，使新增传输内容承担可归因的增量改善。当前没有优先更换 G 注入位置的证据；也不应只优化熵编码后把省下的空流字节当成信息收益。

后续优先级：**表示/有益信息利用 → 有效内容的量化鲁棒性与码率训练 → 真实熵编码效率**。如果将来已证明量化内容有效而只是率贵，再把量化/熵编码作为重点。本轮保持所有模型与协议不变，没有启动新架构训练。
