# 下一轮训练结构：解码端基础运动 + 残余可变形取样 + Bridge后残差融合

日期：2026-11-13。状态：解释性设计，未实现、未启动训练。已有T100/T300的beta扫描只是参照评测，不改变网络；本文明确需要结构实验时的下一轮训练方案。

## 一、问题与可证伪假设

本地复核显示旧matcher在运动场景显著低估运动，在近静止场景引入多余位移，T/U质量几乎重合。因此先检验：提供有用的基础运动，并允许局部多位置取样，是否比相同容量但没有基础运动的网络提供更好的质量—稳定性折中。

不假定更低EPE必然产生更好重建；不假定准确光流完全适合18通道压缩latent；不保证DCN消除插值模糊或decoder aliasing。

## 二、基座、位置与状态

基座为完整B300组合权重，保留现有TCG与LoRA(s=0.5)。codec/entropy/Bridge/de-tokenizer/TCG/LoRA均冻结参数，允许生成器把输出损失梯度传回新增分支。

```text
码流 → 冻结codec → f_t [B,256,H/8,W/8] → 冻结Bridge → l_t [B,18,H/16,W/16]
                                                             │
                                                             ├───────────────┐
上一帧raw latent buffer → 可学习取样 → 对齐历史 → 残差融合 → beta*q*delta       (+)
                              ↑                                              │
独立冻结Original参考RGB → 冻结预训练flow → 基础位移                          l'_t
                                                                             ↓
                                                      冻结de-tokenizer + TCG + LoRA
                                                                             ↓
                                                                           y_t
```

H/W是padding后的尺寸。只用当前和上一帧，raw latent缓存逐帧更新，缓存的是l_t，不是l'_t；新分支的修正不反复写回该buffer。B300已有TCG仍有自己的递归状态。首帧、I帧、GOP/分辨率切换、历史缺失按现有协议reset并旁路新增修正。不得写回codec DPB。

## 三、基础运动从哪里来

复用已审计的预训练RAFT作为第一版参考估计器，冻结它；输入为同一码流独立Original重建的RGB x_ref_t与x_ref_prev，不用GT，也不使用新分支的输出。其好处是训练/推理同源、没有当前输出与当前运动互相依赖的环路；不把压缩伪影当成已解决。

u_t=RAFT(x_ref_t,x_ref_prev)表示当前坐标到上一帧的采样位移。必须按padding与坐标约定缩放空间尺寸和向量单位；当参考RGB与latent相差16倍时，u_lat=resize(u)/16。若先缩小参考RGB估流，需组合计算比例，不能再盲目除16。

Original参考RGB可能要求额外的独立生成器forward，RAFT本身也有成本。训练可缓存，但部署成本必须如实计入；该版首先是机制参考，不宣称已经满足GVC-RT实时目标。只有获得收益后才考虑蒸馏成feature域轻量运动器。

## 四、可变形取样具体做什么

1. 使用固定训练集统计量归一化当前/历史18通道latent。
2. 基础光流粗warp历史，只把粗结果作为位置预测网络的线索。
3. 一个小CNN根据当前latent、粗warp历史、差异、基础位移及QP预测3×3共9个采样位置：18个残余offset通道和9个modulation通道。第一版单deform group，隐藏宽度64作为明确工程默认，不称最优配置。
4. 残余offset用R*tanh限制幅度；首版R=1 latent格作为局部修正预算，声明为假设，不照搬BasicVSR++原特征尺度的上限。offset头末层零初始化，初始offset残差为0，调制sigmoid为0.5。
5. 从原始、未经warp的历史latent取样：

   a_t(p)=sum_k W_k m_k(p) v_k(p) l_prev(p+p_k+u_lat(p)+delta_p_k(p))

   p_k是3×3常规采样位置，delta_p_k为可学习修正，m_k为独立sigmoid权重，v_k排除越界取样，W_k是可学习通道混合卷积权重。它不是归一化的概率加权平均。

最终只对raw历史进行这一次取样；不能先把历史warp成临时图，再把同一临时图作为DCN输入反复重采样。DCN内部仍涉及亚像素插值，不能说它不会模糊。

## 五、怎么融合，谁判断可靠性

保持已有融合主干的54→64、两个残差块、64→18输出结构：输入当前latent、对齐历史和两者绝对差，输出18通道修正delta。最后输出卷积零初始化，保证step0等于B300。

空间门控q由小网络预测。其输入包含上述差异、QP与解码侧一致性线索；可复用原59通道接口，将旧matcher的两个证据通道替换为参考RGB的光度差与前后向flow一致性残差，两组用完全相同的定义。反向flow也只在已收到的t和t-1之间计算，不使用未来帧。几何有效性不等于遮挡真值，这些线索也不是真实置信概率。

l'_t=l_t+beta*q_t*delta_t。beta为新增分支推理强度，首版训练beta=1，开发评估再扫0/0.25/0.5/1；不同beta独立rollout。q与delta可相互缩放，因此不以q图是否好看判定成功。

修正后的l'_t仍按旧实验接口同时进入conv_in和AdaGN条件；本轮不同时拆分AdaGN，避免变化范围再次扩张。固定底座只能保证权重没变，不能保证其对新latent的响应不会损伤纹理。

## 六、两个训练对照

|项目|A：无基础运动|B：基础运动引导|
|---|---|---|
|B300基座|相同冻结|相同冻结|
|基础位移u|0|冻结RAFT在解码参考RGB上的预测|
|局部offset/mask网络|可训练|相同容量、可训练|
|融合与q网络|可训练|同结构、同初始化、可训练|
|当前帧直通、buffer、QP、loss、采样计划|匹配|匹配|

A仍然可以通过局部offset学习对齐，不叫完全无对齐组。两组差异是外部基础运动是否引导粗对应与取样；不能把所有收益都叫DCN收益。旧S/U/T只能作为历史参考，不能与新组作单变量归因。若要单独归因DCN，还需第三个flow+普通warp匹配组，本轮先不宣称该结论。

初始各组都从同一B300开始、新分支零输出，不从T100/T300续训。每组上限300步，50/100/200/300检查，四帧短段通过既有TCG保留段内跨帧梯度；不扩大数据集作为同轮变量。连续64帧开发验证，使用预先隔离的数据；视频和码率规则固定。训练crop/full-frame分布差异仍在本轮风险记录中。

## 七、loss的重要澄清

两组保持空间和时序重建目标一致：

L_sp = LPIPS_Alex + 0.5*DISTS + 0.1383589249*RGB_L1
L_temp = GT参考的MC-RGB变化残差 + 0.5*GT参考的MC-Sobel变化残差
L = L_sp + lambda_temp*L_temp

结构归因试验暂沿用旧lambda_temp=4.63349060748，作为受控起点而非最优值，报告参数空间梯度与实际质量取舍。GT与GT-flow仅用于监督/评价。

**旧0.1*L_align不机械保留。** 旧项监督单一motion field；新flow冻结，9个取样offset还要学习不同邻域与通道任务，不能强迫所有offset都等于同一GT-flow。新局部offset由最终重建目标训练，使用幅度限制避免失控。这是相对于旧T的训练目标变化，必须声明；A/B之间目标保持一致。

不在这次结构对照里同时增加GAN、滤波、HF-shuttle或重调多个loss。它们可作为后续独立因素，不声称本结构已经具有其作用。

## 八、理论依据与判定

对应误差的一阶近似：历史特征采样误差约为局部空间梯度乘以位移误差；这解释了细边缘为何对错位敏感，但只在局部光滑、小误差近似下成立。基础位移加局部残余可减少学习完整大位移的负担；多点取样增加匹配与内容组合自由度，代价是仍可能混合错误历史。

来源：BasicVSR++ arXiv:2104.13371 Sec3.2及作者公开basicvsr_pp.py中的SecondOrderDeformableAlignment。原作采用二阶双向传播、SPyNet等；本方案是因果单历史、18通道latent上的迁移，不是完整复现。

本轮已读取原文HTML https://arxiv.org/html/2104.13371v1 第3.2节式(3)-(5)、Fig3及Discussion；另核对作者源码 https://raw.githubusercontent.com/ckkelvinchan/BasicVSR_PlusPlus/master/mmedit/models/backbones/sr_backbones/basicvsr_pp.py 。文献将光流作为基础偏移，预warp特征帮助预测，DCN最终作用于unwarped feature；这支持所借鉴模块的定义。

VideoGigaGAN arXiv:2404.12388v2 Sec3.3–3.5显示传播也可能导致模糊，需要独立处理混叠和细节保留。因此本方案不能承诺消除aliasing或替代HF-shuttle；它只检验可靠历史采样这一个瓶颈。

本轮已核对 https://arxiv.org/html/2404.12388v2 第3.5节及Fig5；文献本身报告传播/BlurPool变糊、HF-shuttle恢复高频，不能把“加入对齐”当成不损锐度的充分条件。

验收：同码率下，逐视频的LPIPS/DISTS—RWE/MC误差曲线是否优于无基础运动组与简单模糊参照；原分辨率视频是否减少跳变而不增加明显拖影/细节扩散。允许单项指标小幅取舍，不接受只靠总loss/EPE/边缘能量判断。无法得到可复核优势则不扩大训练；候选有效再扩展QP与隔离开发源，最后锁定测试和各数据集含Original的R–D曲线。
