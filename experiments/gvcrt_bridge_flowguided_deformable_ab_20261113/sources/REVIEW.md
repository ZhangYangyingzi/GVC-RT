# Bridge 后历史对齐与残差融合：完成结果复核

日期：2026-11-12。范围：只复核已有训练、指标、权重凭据、运动缓存及原分辨率定帧；本次未启动 GPU 训练/推理，未改动原始实验代码和检查点。

## 结论

**工程执行完成，早期有小幅重建收益，但尚未证明“有效对齐历史，保留锐度并消除闪烁”。不建议按原配方继续扩大联合训练。**

- T100 在 ULong 4 个开发源、QP5 的平均 PSNR/LPIPS/DISTS/FloLPIPS 均改善，值得保留作候选；它不是所有视频、所有 QP 的已验证最佳模型。
- T300 相比 B300 的 PSNR 与 DISTS 改善，但 ULong QP5 的 LPIPS/FloLPIPS 已回退；边缘能量继续减弱。
- T 与 U 极为接近。新增独立复核发现，MotionAligner 在已有开发帧上的误差没有实质优于零位移，近静止场景反而更差。原报告仅比较预训练随机初始化与 500 步，缺少这项关键基准。
- 门控有效位置的数值仍集中在约 0.5，尚无证据它学会了强的可靠/不可靠历史区分；但不能由此断言网络完全不用历史。
- 所有比较保持相同缓存码流 bpp；Original 独立基线已在本轮图中。B300 是现有组合模型，不能当作 Original，也不能把累计收益全算成新模块收益。

## 1. 实验做了什么，完成了什么

冻结 B300 的 codec、Bridge、de-tokenizer 原主干、现有 TCG 与 LoRA；在 Bridge 的 18 通道输出后、de-tokenizer 前加入新分支。

- S_current：新增分支只看当前 latent；**B300 自身的 TCG 仍有历史**。
- U_unaligned：看当前及上一帧原始 Bridge latent，保留 matching evidence，但 latent warp 位移强制为零。
- T_aligned：由当前/历史 decoded feature 预测位移，warp 历史原始 latent，再做可学习残差融合。

公式是 `l_corrected = l_current + q * delta`，不是原来对当前与递归修正 latent 做凸平均。buffer 缓存未经修正的原始 latent，避免旧融合结果反复写回；但这不自动保证无模糊、无拖影。修改后的 latent 同时进入生成器卷积输入和 AdaGN 统计，因此局部改动可能影响全局。

MotionAligner 预训练 500 步，S/U/T 各 300 步，单 seed。32 个 ULong 训练源，128 个固定时间窗口及固定 256×256 RGB crop；QP0/5/9。训练 crop 先于 codec，所以 crop 与全图的特征/归一化分布差异仍是迁移风险。

本次独立复核：123 个视频×QP×模型点、1968 帧记录；所有点 bpp 相同且完成凭据中的码流/decoded-feature 哈希一致；S/U/T 的 step0 指标与 B300 完全相同；T100/T300/U300/S300 实际文件 SHA 与落盘凭据匹配。未发现仍在运行的本实验 Python 进程。原审计记录冻结参数、原始缓存、因果状态、坐标换算、零分支恒等及梯度贯通检查通过。

指标覆盖：ULong 4 源、UVG 仅 Bosphorus 1 源；每个数值评测点只有 16 帧重置短片。两个可视化案例输出 64 帧，但 64 帧不等于都完成了正式指标评测。135 点最终测试未使用；没有本轮 HEVC/MCL-JCV 曲线。

## 3. 为什么“对齐后融合”的预期没有兑现

### 3.1 最直接证据：历史实际上没有被充分对准

用保存的原始 GT-RAFT 伪标签、相同有效掩码、相同 padding/坐标缩放，比较已有 T100/T300 运动缓存与**零位移**。每源检查 local frame 2–15 共 14 对，合计 56 对；frame1 没有新模块历史，排除。下面是 T300，统一换算为 RGB 像素单位：

|开发场景|参考平均位移 / 零位移 EPE|预测平均位移|T300 EPE|
|---|---:|---:|---:|
|近静止细纹理 24747b35|0.0673|0.4470|0.4711|
|近静止细纹理 72329914|0.1474|0.5831|0.5377|
|镜头运动 de12efc2|19.9550|1.3354|20.1287|
|动态/遮挡候选 0aa91dd0|14.5274|1.0705|14.4914|

EPE 是预测二维位移向量与 RAFT 伪标签的端点误差，**不是最终图像误差，也不是真实物理运动真值**。高运动源的预测量级不足：应搬动约 20 像素的地方，平均只搬动约 1.3 像素。近静止两个源的全部 28 对中，T300 都不如零位移。镜头运动源 14 对也全部不如零位移。

T100 对镜头运动的平均 EPE 相比零位移仅改善 0.178%；动态源反而差 0.303%。T300 动态源平均仅改善 0.248%。因此不能说“我们已经实现准确对齐，只是融合无效”。更准确的说法是：**准确对齐这个前提在此 pilot 中没有建立。** 这也解释了 T/U 为什么接近。

原报告的 pretrain500 相比随机初始 EPE 下降约 10%，不代表已具备有效对齐能力；随机初始基线可能比不对齐还差。此次新增的零位移核验比单看 loss 下降更有判别力。

### 3.2 q 还不是学成的“可靠性判断”

排除无历史帧和几何无效位置后，T300 各源 q 均值为 0.4962–0.4995，标准差约 0.0064–0.0113；5%–95% 分位大致在 0.48–0.512。T100 更集中在约 0.50。

空间选择幅度很小，不能从它解释“运动区域关闭历史、静止区域充分复用”。当前 hard validity 只判断越界/候选几何可用，不等于遮挡或对应关系正确。q 与 delta 只以乘积进入输出，存在尺度可互相补偿的问题，因此 q 的绝对值本身也不是校准过的可靠性概率。

这不证明融合分支完全忽略历史：delta 网络仍可利用当前/历史差异。要区分“有用历史”和“仅增加当前帧变换容量”，需后续冻结检查点下的历史替换/位移替换对照。

### 3.3 当前优化更偏向降低平均残差，细节损失仍存在

当前实际 loss：

```text
L_sp = LPIPS_Alex + 0.5 DISTS + 0.1383589249 RGB_L1
L_temp = masked motion-compensated RGB change residual against GT
       + 0.5 signed normalized Sobel change residual against GT
L_total = L_sp + 4.63349060748 L_temp + 0.1 L_align  (U/T)
```

这是本轮配方，不是直接复现 GVC-RT 原文全部训练损失。时序权重按 8 个训练段的**输出 RGB 梯度**校准为 0.1×空间梯度量级；不能保证投影到新增模块参数后仍保持该比例，更不能保证整个训练期间始终平衡。

在相同四个固定诊断训练段上，T0→T300 的 L_sp 从 0.120530 变为 0.123585（变差），L_temp 从 0.015588 变为 0.014694（下降），总目标从 0.238647 微降至 0.238207。模型可通过牺牲部分空间项换取更低的加权总目标。**这支持存在优化取舍，但尚不足以断言唯一根因就是时序权重过大。**

T300 ULong QP5 的 MC-Sobel -3.569%，边缘强度 -4.517%，高频能量约 -7.69%；B300 的平均边缘强度本来就低于 GT。不能把 MC-Sobel 的降幅直接称为“人眼闪烁减少 3.569%”。

同时高频对 GT 的误差 MSE 也下降约 3.664%，所以也不能声称收益全部来自恶性模糊：削弱错误纹理同样可能降低误差。当前证据是“部分更接近 GT，同时存在细节收缩及感知回退”，没有证实稳定与锐度同时改善。

## 4. 代码是否做错

检查了 model.py、train.py、objective.py、temporal.py、evaluate.py 及相应审计。未发现把 GT-flow 接入推理、码率变化、基座意外解冻、残差零初始化导致 step0 掉画质、显然反向的采样坐标或梯度全断等问题。

代码实现了预定的匹配、warp、残差融合、raw-latent buffer、四帧 TCG 梯度链。**但实现存在不等于匹配/可靠性已经学会。** 当前最明确的是学习效果未达前提，不宜直接宣布该机制理论失效，也不宜仅靠继续增大步数期待它自行修好。

可能参与的因素（未完成因果验证）：500 步小型匹配预训练及数据覆盖有限；联合训练允许用更容易的当前帧修正降低损失；GT-RGB 流与压缩特征的对应并不完全一致；训练 crop 和全分辨率特征分布不同；修改 18 通道 latent 同时影响 AdaGN 统计。不可将这些猜测当成已证实根因。

## 5. 接下来建议

1. 保持 B300 为稳定参照，保存 T100/U100 为候选；暂不把 T300 替换为主模型，也不扩大当前联合训练。
2. 下一道关卡应是 MotionAligner 能否在相同 decoded features 上胜过零位移：分静止/移动/遮挡，检查向量幅值、方向、EPE，以及 warp 后历史特征/latent 的对应误差。先解决这一局部机制，不能只验训练 loss 下降。
3. 必要的冻结模型反事实：同一融合权重下比较预测位移、零位移和仅作诊断的 GT-RAFT 位移。若 GT-RAFT 也不能改善融合输出，则不能只归咎 matcher；若 GT-RAFT 有效而预测无效，才有依据投入 matcher 训练。所有部署推理仍只用解码端信息。
4. 若要投入新训练，优先局部改进/预训练 matcher（含覆盖静止与大位移、全图特征分布的采样），先通过上述关卡，再短程联合；不同时开放 Bridge/decoder、修改多个 loss 或再加 GAN，以免重复失去归因。具体结构选择应待局部证据，不把“多训练一些”当作答案。
5. 最终质量验收要补完整 64 帧或更长连续 rollout，联合观察 LPIPS/DISTS、MC 残差、相对 GT 的锐度/高频误差及原分辨率无损视频。不能要求所有标量同时最优，也不能接受靠抹平纹理降低时序残差。跨数据集/跨 QP 保留独立曲线。T100 目前只有 QP5 数值，不可直接宣布其多 QP 最优。

当前 FP32 参考实现，B300 端到端约 150.51ms/帧，T300 约 184.51ms/帧（约 +22.6%）；没有足够对齐收益时，这项开销也不值得直接进入大规模方案。该数字不是优化部署后的实时性能结论。
