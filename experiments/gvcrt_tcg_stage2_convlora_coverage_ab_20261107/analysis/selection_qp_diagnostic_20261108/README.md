## 缩放实验边界

提议先只测 A2000，QP9，32 个开发视频，额外旁路增益 s=0.5。s=0/1 用完整序列 smoke 验证端点后复用既有基线/A2000 指标。不能插值现有指标或混合末端 RGB 替代真正分支缩放；多层与历史缓存使整体输出不必对 s 线性。

当前实现 intrinsic alpha=rank=4，alpha/r=1；新乘数应单独记 s，避免把 alpha 直接设置 0.5 而得到 0.125 的错误总倍率。第一轮按实验 external QP 固定整段 P 帧的 s，不随内部 QP 调度跳变。

若 DISTS 改善只是退回 s=0 且丢失 FloLPIPS 增益，只说明折中。若中间 s 优于 s=1 或有更优复合收益，可支持强度过大假说；还需 QP0/5 的相同缩放对照才能确认 QP 关联。

## UVG

HoneyBee 与 Jockey 的 A2000 平均 FloLPIPS 分别比原版高 2.7344%、1.7723%，但并非每个 QP 都差。HoneyBee QP0/5 差、QP9 好；Jockey 仅 QP5 差，QP0/9 好。DISTS 中 HoneyBee 平均 +1.5482%，Jockey -9.9945%。LoRA 相对 TCG 在这两视频的全部 QP 上均改善 FloLPIPS 与 DISTS，故不能把相对原版的剩余退化归因于 LoRA 本身。

两视频源文件为 120fps，本实验取帧 0,4,...,252（有效 30fps）共 64 帧，所有模型用相同采样。这不是完整 UVG 评测。本次直接检查本地源视频的第 0/128/252 帧亮度图：HoneyBee 主要呈现花丛与相近背景，Jockey 可见骑手和马的位置、尺寸及背景明显变化。静态抽帧不足以量化运动强度，不能把两个样本均认定为极端高速运动或证明运动导致退化。

本地源帧见 UVG_source_luma_samples.png（仅亮度展示）。

训练已混合外部 QP0–9，并非只在一个 QP 训练；训练 UVG 视频为 Beauty/ReadySteadyGo/ShakeNDry/YachtRide，两个留出测试视频不能因表现不佳移入训练。
